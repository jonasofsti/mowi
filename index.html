Fôrprognose – regelbasert vurdering (Vest & Midt)

Lokalt verktøy for lakseoppdrett. Leser Excel-eksport av fôrprognose-cuben i nettleseren. Ingen installasjon, ingen server, fungerer offline.

Innstillinger og forutsetninger
Standard følger regelen: faktisk = snitt(w23,w24), prognose = snitt(w25,w26). Uke 27 (splittet) brukes aldri som hel uke i nøkkeltallet.

Hva parseren fant

Valgfritt: lim inn / last opp slaktetall (antall fisk)

Slaktetall ligger ikke i fôr-cuben (de kommer fra biologiplanen). Verktøyet utleder kun «fôr → 0 = slaktes ut». Du kan valgfritt lime inn slaktetall her for å berike slakte-seksjonen. Format pr. linje: Lokalitet;uke;antall eller Lokalitet;antall.

Valgfritt (av som standard): tekstlig AI-vurdering via API
Dette er valgfritt og krever internett + egen API-nøkkel. Kjernen (parsing, beregninger, grafer, regelbaserte flagg) virker helt uten dette. Nøkkelen lagres kun lokalt i denne nettleseren (localStorage) og sendes kun til valgt endepunkt.

Regelbaserte flagg holder mennesket i løkka: verktøyet flagger og forklarer – du bestemmer. Terskel for status: Offensiv ≥ +8 %, Defensiv ≤ −8 %, ellers Realistisk.
